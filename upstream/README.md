# Required TorNet source subset

These files are copied from [MIT Lincoln Laboratory's TorNet repository](https://github.com/mit-ll/tornet/tree/92d9d97bbd174be2e5cea4896c62208c5be7900d),
commit `92d9d97bbd174be2e5cea4896c62208c5be7900d`.

Only the data constants, loader, coordinate preprocessing, Keras CNN, custom
layers, and package initializers required by this study are retained. The source
files are unchanged. Other loaders, display utilities, and training integrations
are available in the authors' full repository.

Preserve [LICENSE](LICENSE) and the distribution notices in the source files.
The authors' v1.1 dataset update documents corrected warning event and episode IDs.
